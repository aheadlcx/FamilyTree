# 家族族谱小程序（微信云开发版 + Web 预览版）

一个功能完整的族谱微信小程序，**零服务器**：基于微信云开发（云函数 + 云数据库 + 云存储），登录、权限、数据、图片全部复用微信免费/内置能力。
另附 **Web 版**（`web/` 目录），业务逻辑与小程序版 1:1 一致，浏览器直接打开即可预览效果。

## 快速预览 Web 版（无需部署）

方式一：直接双击打开 `web/index.html`（数据存在浏览器 localStorage）。

方式二：本地起个静态服务（推荐，剪贴板等功能更完整）：

```bash
node tools/serve-web.js        # 打开 http://localhost:8765
```

Web 版说明：
- **模拟微信登录**：首次进入点「微信一键登录」会创建一个模拟账号（对应小程序的 openid 登录）。
- **多账号联调**：右上角演示身份栏可切换/新建模拟微信账号，用于演示「A 邀请 → B 申请 → A 审批」等多角色场景。
- **逻辑一致**：`web/js/api.js` 是 `cloudfunctions/api/index.js` 的逐行移植——相同的 action 协议、四级角色权限（含 API 层强制校验）、审批流、邀请码、世代算法、循环校验、审计日志；数据结构（六个集合）与字段完全同名，页面结构与交互也一一对应。
- 照片以压缩后的 dataURL 存本地（对应云存储）；「导出 JSON 备份」对应小程序的 shareFileMessage。

## 功能总览

| 模块 | 功能 |
|---|---|
| 微信登录 | openid 自动识别 + 微信「头像昵称填写能力」（官方替代已废弃的 getUserProfile） |

| 成员管理 | 姓名/性别/生卒/籍贯/职业/电话/生平/照片；父母、配偶、子女、同胞关系链；循环校验、世代数自动计算（配偶同世代）；列表按世代分组；选人弹层可直接新建入谱 |
| 大事记 | 时间线按年份分组 + 多图（婚丧嫁娶、寿诞等），图片存云存储 |
| 统计 | 总人数、世代数、在世/已故、性别、平均寿命、最长寿、世代分布、出生年代分布 |

| 家族管理 | 审批、角色调整、移出成员、家族设置、操作审计日志（相对时间）、转让族主、解散家族、导出 JSON 备份 |
| 多家族 | 一个微信号可创建/加入多个家族并随时切换 |

## 部署步骤（约 10 分钟）

1. **导入项目**：微信开发者工具 → 导入本项目 → 填入你的小程序 `appid`（替换 `project.config.json` 里的 `touristappid`）。
2. **开通云开发**：工具栏点「云开发」→ 开通（新用户有免费额度/试用期，个人使用足够）→ 创建环境。
3. **填写环境 ID**（可选）：云开发控制台复制环境 ID，填入 `miniprogram/config.js` 的 `ENV`。留空则使用默认环境。
4. **上传云函数**：右键 `cloudfunctions/api` → 「上传并部署：云端安装依赖」。
5. **数据库集合**：无需手动创建。首次调用遇到「集合不存在」时小程序会自动调用 `initCollections` 创建 `users / families / members / joinRequests / events / auditLogs` 六个集合。
   建议在云开发控制台把这些集合的**权限都设为「仅创建者可读写」**（所有数据访问都走云函数，这样客户端完全无法绕过权限直接读写库）。
6. **运行**：第一个使用者注册后会自动成为该家族「族主」。

> 可选：在云开发控制台给 `members.familyId`、`events.familyId`、`joinRequests.familyId+status` 建索引，数据量大时更快。

## 权限模型

| 能力 | 浏览 viewer | 编辑员 editor | 管理员 admin | 族主 owner |
|---|---|---|---|---|
| 查看族谱/成员/大事记/统计 | ✅ | ✅ | ✅ | ✅ |
| 添加/修改成员、发布大事记 | ❌ | ✅ | ✅ | ✅ |
| 删除成员 | ❌ | ❌ | ✅ | ✅ |
| 审批加入、邀请码、家族设置 | ❌ | ❌ | ✅ | ✅ |
| 设管理员/移出管理员 | ❌ | ❌ | ❌(需族主) | ✅ |
| 转让族主、解散家族、导出备份 | ❌ | ❌ | ❌ | ✅ |

- 权限校验在**云函数端强制执行**（`requireRole`），客户端仅负责按角色显隐界面。
- 敏感操作写入 `auditLogs` 审计日志（谁在什么时候做了什么）。
- 昵称/简介/大事记文本接入微信内容安全 `msgSecCheck`（云调用，未开通时自动跳过，不阻塞）。

## 复用的微信免费资源

- **云开发**：云函数、云数据库、云存储（新用户免费额度，无需自建服务器/域名/HTTPS）
- **微信登录**：云函数自动取 openid，无需配置
- **头像昵称填写能力**：`open-type="chooseAvatar"` + `input type="nickname"`（官方推荐的登录态资料获取方式）
- **转发分享**：`onShareAppMessage` 邀请卡片直接跳转加入页
- **内容安全**：`security.msgSecCheck` 云调用
- **文件消息分享**：`wx.shareFileMessage` 导出族谱 JSON 备份
- 云文件 ID 可直接用于 `<image>` 组件，无需临时链接

## 数据模型（云数据库集合）

- `users`：openid、昵称、头像、`families[{familyId, role, memberId, joinedAt}]`、currentFamilyId
- `families`：名称、姓氏、简介、邀请码、autoApprove、defaultRole、creatorOpenid
- `members`：familyId、姓名、性别、生卒、在世、籍贯、职业、电话、生平、照片 fileID、fatherId/motherId、spouseIds[]、generation（自动）
- `joinRequests`：申请与审批状态
- `events`：大事记（标题/日期/描述/图片）
- `auditLogs`：操作日志

## 说明与约定

- 族谱树默认**父系优先挂接**：同时有父母时子女挂在父亲节点下、母亲以配偶卡展示；单亲家庭自动挂到在谱的一方。
- 新成员默认角色为「浏览」，可在管理页改为「编辑员」或开启自动通过。
- 「设为本人」会把族谱中的某个成员标记为你自己，用于列表/树上的高亮定位。
- 云开发超出免费额度后按量计费（小家族用量极低）；如需完全零成本，可把 `utils/api.js` 指向自建后端，云函数逻辑可直接移植（都是 Node）。
